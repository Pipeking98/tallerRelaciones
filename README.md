# Taller III - Sistema de Reservas de Hotel

Proyecto en C# para la gestión de habitaciones, clientes, consumos y cobros de un hotel.

##  Integrantes
* Integrante 1: Andres Felipe Rey Amezquita
* Integrante 2: Jose Luis Gutierrez Machado

## Requisitos del Taller Implementados
* **Clases y Objetos:** Uso de las 7 clases solicitadas (`Cliente`, `Habitacion`, `Servicio`, `Categoria`, `Reserva`, `Empleado` y `Cobro`).
* **Encapsulamiento:** Propiedades privadas y métodos de acceso.
* **Colecciones:** Uso de `List<T>` para manejar los servicios adicionales y las reservas.
* **Cálculos:** Métodos automáticos para contar noches y sumar los costos de la estadía.

## Cómo ejecutar
1. Abrir el proyecto en Visual Studio.
2. Presionar `F5` o ejecutar `dotnet run` en la terminal para correr la simulación en consola.
